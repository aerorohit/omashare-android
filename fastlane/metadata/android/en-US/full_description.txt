Start a transfer with someone nearby, then walk away. The file keeps moving in the background, over mobile data if you leave Wi-Fi. You do not have to stay next to each other until it finishes.

The transfer is peer to peer and encrypted. The file goes from one device to the other. No server keeps a copy. On the same Wi-Fi that path is the local network, so large files are fast. If you leave Wi-Fi, the transfer continues over mobile data. A relay is used only to connect the two devices when they cannot reach each other directly. It cannot read the file.

Two phones can do this with each other, and a phone can do it with a Linux computer running Omashare. The other person accepts before anything is saved. Send from Omashare, or from the share menu in another app. Accepted files are saved in Downloads/Omashare.
